# Contributing / 贡献指南

中文：欢迎 Issue / PR。请勿提交 `.env`、Bot Token 或 Chat ID。提交前运行 `python3 test_static.py`，Shell 脚本至少通过 `bash -n`。风险判断必须标注启发式边界。

English: Issues and PRs are welcome. Never commit `.env`, Bot Tokens or Chat IDs. Run `python3 test_static.py` before submitting and validate shell scripts with `bash -n`. Risk conclusions must clearly state their heuristic limits.
