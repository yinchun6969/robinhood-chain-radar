# Robinhood Chain Radar

## 中文

Robinhood Chain 主网（Chain ID `4663`）实时资金雷达：监控百万美元级跨链、Uniswap V2/V3/V4 流动性、大额 Swap、地址画像、Token CA/持有人/LP/合约风险，并通过 Telegram 与本地 Dashboard 推送。

- Android / Termux：`bash scripts/android/install-termux.sh`
- Ubuntu：`sudo bash scripts/ubuntu/install.sh`
- Telegram 中文：`LANGUAGE=zh_CN`
- 中文 Dashboard：`http://127.0.0.1:8787/zh`

## English

A real-time Robinhood Chain mainnet (Chain ID `4663`) capital-flow radar for large bridge inflows, Uniswap V2/V3/V4 liquidity, large swaps, address intelligence, token CA/holders/LP status and heuristic contract-risk checks. Alerts are delivered through Telegram and a local Dashboard.

- Android / Termux: `bash scripts/android/install-termux.sh`
- Ubuntu: `sudo bash scripts/ubuntu/install.sh`
- English Telegram: `LANGUAGE=en_US`
- English Dashboard: `http://127.0.0.1:8787/en`
